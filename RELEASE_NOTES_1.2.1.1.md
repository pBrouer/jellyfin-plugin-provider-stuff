## Config page button fix

Fixes illegible buttons (white text on light background) on the ProviderStuff settings page in Jellyfin dark theme.

### Fixed

- **Add provider**, **Refresh TMDB providers**, and **Remove** buttons now use readable contrast (`raised` styling).

### Includes

All changes from **1.2.1.0** (Jellyfin 10.11+ scheduled task and collection logo fixes).

### Install

`https://raw.githubusercontent.com/pBrouer/jellyfin-plugin-provider-stuff/main/manifest.json`

Update **ProviderStuff** to **1.2.1.1** from the catalog and restart Jellyfin.
